# onyx-cli

Mine ONYX from your terminal.

    npm install -g ./cli        # from the onyx project folder (or from npm once published)
    onyx login <API_KEY>      # key from the website after connecting a wallet
    onyx mine                 # uses all CPU cores but one; --threads N to change
    onyx status

Point it at another server with `--server https://your-site` or `ONYX_SERVER`.
