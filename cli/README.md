# orrery-cli

Mine ORRERY from your terminal.

    npm install -g ./cli        # from the orrery project folder (or from npm once published)
    orrery login <API_KEY>      # key from the website after connecting a wallet
    orrery mine                 # uses all CPU cores but one; --threads N to change
    orrery status

Point it at another server with `--server https://your-site` or `ORRERY_SERVER`.
